Kruschke diagram = your model as a network of distribution curves, including hierarchical structure — kept live in sync with the compact McElreath notation
What is this about?
On the left, the Kruschke diagram builds your model as a network of distribution curves — including the hierarchical structure that arises quite naturally from Bayesian parameter estimation, with every parameter visibly linked by an arrow to its prior. On the right, the McElreath notation translates the same model into compact formulas: every stochastic ("~") and deterministic ("=") relationship, plus all prior assumptions, is spelled out explicitly there — both views stay live in sync, wherever you change something.

A note on scope: this tool deliberately shows only a basic model — the goal is to understand and visualize the concept of hierarchical Bayesian model structure in the style of Kruschke's diagrams, not to represent a complete model tailored to your own data. Accordingly, only limited example models can be loaded (up to 4 predictors, one grouping structure, a few likelihoods to choose from).
How to proceed
1 · Likelihood — distribution family of the outcome variable
2 · Variables — set the outcome and predictors
3 · Structure — optional: multilevel model with random intercept and/or slopes
4 · Priors — set per parameter, visible live in both the diagram and the notation
5 · Detail level — standard or full view of diagram and formulas
And next?
Once the model structure is settled, continue to more complex models tailored to your own data in the brms Model Builder (button "Next → brms Builder" above) — there it becomes runnable R code with any number of predictors, real data variables and sampling settings. For special cases such as mixture models, splines or Gaussian-process terms, the Advanced Model Builder builds on that. For a quick prior predictive simulation right here, "⬡ Golem light" above generates matching R simulation code for this (limited) model. New here?     Reading and understanding Kruschke diagrams


    This tool shows you the graphical model structure of Bayesian regression models — live, interactive, in simple examples:


    · ○ open circles = unknown parameters that need priors (α, β, σ)

    · □ rectangle = observed data y

    · • dot = deterministic node (μᵢ) — no prior, computed from inputs

    · Arrows show the generative direction: Prior → Parameter → Data

    · Plates (dashed frames) mark repeated units (i = 1…N observations; j = 1…J groups)


    In the hierarchical model, each group j receives a deviation from the global intercept: u₀ⱼ ~ Normal(0, τ₀). τ₀ controls the degree of partial pooling — small τ₀ = strong shrinkage. In McElreath (Ch. 14, p. 441 ff.) this parameter is called σ_α. Random Slopes are implemented here only for the first predictor. Once they're active, u₀ⱼ and u₁ⱼ are NOT drawn independently anymore — jointly, [u₀ⱼ,u₁ⱼ] ~ MVNormal(0, Σ), with an additional correlation ρ between the intercept and slope deviations (brms default).
